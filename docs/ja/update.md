# FAIRe ニュース＆更新情報
FAIRe ガイドラインの改善を継続的に行っています。最新の更新、新しい展開、進行中の活動はこのページで随時ご確認ください！

### 2026-06-15 : FAIReチェックリスト日本語版 ###
日本のeDNAコミュニティからの要望に応え、FAIReメタデータチェックリストの日本語訳を作成しました。翻訳の取りまとめを行ってくださった中村正敏様（IDEA Consultants, Inc.）に心より感謝いたします。日本語版は以下からダウンロードできます： [ここをクリック](https://github.com/FAIR-eDNA/FAIRe_checklist/blob/main/FAIRe_checklist_v1.0.2_JP.xlsx)。

### 2025-11-13 : TDWG/GSC の協働 ###
2025年初頭に、TDWGおよびGSCのeDNAタスクグループを、既存メンバーと新たなFAIReメンバーで発足させました。我々の目標は、TDWGおよびGSCの枠組みの下で Darwin Core（DwC）および MIxS における eDNA チェックリストを開発することです。  
この取り組みは、主に DwC と MIxS 標準を用いる GBIF、OBIS、INSDC といった確立されたデータベースと FAIRe を橋渡しするために重要です。詳細は以下をご参照ください：

- [TDWG eDNA task group](https://www.tdwg.org/community/gbwg/enviro/)
- [GSC eDNA task group](https://www.gensc.org/pages/projects/eDNA-project.html)
- Takahashi et al. (2026) A TDWG and GSC Collaborative Initiative To Develop an Environmental DNA (eDNA) Metadata Checklist. doi: [10.3897/biss.10.185867](https://biss.pensoft.net/article/185867/)

### 2025-11-13 : FAIRe コーディング作業部会 ###
FAIReのスクリプトおよびツールの開発に特化した「FAIRe コーディング作業部会」を立ち上げたことをお知らせします。  
このグループはコーディング経験があり、FAIR原則に熱意を持つメンバーで構成されています。我々の目標は、コミュニティがワークフロー内でFAIReガイドラインを採用できるよう支援するスクリプトやツールを作成し、データのフォーマット自動化、マッピング、提出を容易にし、FAIRe実践の普及を促進することです。これらのツールは **R** と **Python** の両方で新たなパッケージとして開発する予定です。

## FAIRe ワークショップ ##
FAIReワークフローの導入支援のため、世界各地のパートナーと協力して定期的にワークショップを開催しています。

### 自習型オンライン教材 ###
対面ワークショップに参加できない方のために、自習型のオンライン教材を無料で公開しています。  
これらの教材は元々 [OBON FAIR eDNA Workshop](https://obon-ocean.org/2026/07/09/obon-fair-edna-workshop/) のために作成されたもので、FAIRe と [BeBOP](https://bebop-obon.github.io/) の標準、[OBIS](https://obis.org/) のデータ公開ワークフローをカバーし、デモ用データセットを用いたハンズオン演習を含んでいます。ご自身のペースで、手元のデータを使って実践できます。
